# Security

If you find something in this repository that could put a person's mail
or token at risk, write to security@elchi.dev. Say what you found, how to
reproduce it and, if you have one, what you would change. You get an
answer within two working days and a fix as fast as the finding needs,
with credit if you want it.

Please do not open an issue for it, and please do not try it against
mailboxes that are not yours.

The service itself, its API and its infrastructure are covered by the
same address.
